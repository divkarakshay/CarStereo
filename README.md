# SerialDump\n\nSerialDump is a minimal Android application that connects to the stereo’s serial port, dumps the raw data stream from the MCU, and displays it in real time. It serves as a debugging aid and a foundation for building higher‑level CAN‑bus features.\n\n## Features\n- **Foreground service** that reads `/dev/ttyS0` (or alternatives) and writes to `/sdcard/SerialDump/serial_dump.txt`.\n- **Real‑time UI** showing status, bytes written, and the last received data line.\n- **Share** the dump file via Android’s share sheet.\n- **Broadcast** progress updates to the UI.\n\n## Build & Run\n```bash\n# From the project root\n./gradlew assembleDebug\nadb install -r app/build/outputs/apk/debug/app-debug.apk\nadb shell am start -n com.cardumper/.SerialDumpActivity\n```\n\n## Change Log\n\nSee the [CHANGELOG.md](CHANGELOG.md) for a detailed list of recent changes.\n
